# 工件模型功能使用与验证

日期：2026-10-30  
适用项目：robot3d_demo  
状态：实施记录草稿。本文区分当前操作方式、保护上限与验收结果；最终构建、CAD 运行和兼容性结论须按实际测试回填。

## 1. 首期范围

本次实现的业务流程为：选择一个工件文件，在独立窗口加载并核对预览，确认单位、轴向、组件、原点和初始位姿后导入当前机械臂场景，再进行定位、显示管理、撤销重做及保存恢复。

| 内容 | 当前实现范围 |
| --- | --- |
| 文件入口 | STEP/STP、IGES/IGS、STL、OBJ、PLY；CAD 入口要求启用并正确部署 OCCT |
| CAD | OCCT 7.9.1 读取 STEP/IGES、XDE 组件层级与基础属性、曲面离散 |
| 网格 | STL、OBJ 有效面、OBJ/MTL 基础颜色、带面拓扑的 PLY；仅顶点的 PLY 以点云提示拒绝 |
| 预览 | 组件勾选和高亮定位、尺寸、单位、轴向、原点、七种标准观察方向、实体/线框/实体带边线 |
| 场景 | 多实例、选择、数值定位、父系绑定、重命名、显隐、锁定、颜色、不透明度、局部轴、删除 |
| 恢复操作 | 工件撤销重做、以 `.r3wp` 保存和打开自包含工件场景包 |
| 渲染 | 现有 OpenGL 与 VTK 后端共用工件资产及实例状态 |

表面选点、测量、轨迹关联、碰撞、可达性、路径生成、模型编辑和二维图纸处理尚未纳入本次实现。支持格式名称表示已接入对应读取链路，具体协议、实体及客户模型兼容性仍以验证清单为准。

## 2. 导入工件

1. 打开主界面的“工件”页签，点击“导入工件…”。
2. 点击“选择文件…”或输入文件路径，然后点击“加载预览”。每次会话读取一个主文件及其必要依赖。
3. 等待解析和网格生成。加载期间可点击“取消加载”；取消窗口或按 Esc 将放弃尚未提交的会话。
4. 检查左侧组件树。默认保留全部组件，可取消勾选不需要的组件；选择某一项可高亮并定位观察。至少需要保留有效表面。
5. 核对右侧尺寸、面数和警告，再设置单位、方向、原点、父坐标系和初始位姿。
6. 等待当前参数的预览重新生成。“导入场景”只有在候选有效且预览资源准备成功后才可用。
7. 点击“导入场景”。提交成功后窗口关闭，新实例加入对象列表并被选中。

同一个文件可以连续导入多次，各次形成独立实例；改变其中一个实例的位姿或显隐不会改变其他实例。单次弹窗只允许一次成功提交。解析、规范化或场景资源准备失败时，当前正式工件集合保留，状态区显示失败信息。

### 2.1 单位与尺寸

- 场景业务长度统一为 **mm**，角度使用 **°**。
- STL、OBJ 和 PLY 通常没有可信的长度单位。显示“请选择单位（未知）”时必须主动选择 mm、cm、m、in，或填写“每个读入坐标单位对应多少 mm”的自定义比例。
- STEP/IGES 通过 OCCT 转换为 mm 后进入预览。此时“读入坐标单位”为 mm；源 STEP 声明的单位可能另见诊断，不能再次因源文件声明为 m 而乘 1000。
- 覆盖单位会改变实际几何尺寸。修改后应再次核对包围盒尺寸，再提交场景。
- 主视口的历史显示比例由渲染层统一处理；用户无需在工件比例中补偿该比例。

### 2.2 轴向、原点和位姿

目标工件局部系为右手系，Z 向上、X 向前。“源上方向”和“源前方向”应选择不同的源轴，必要时勾选“源模型为左手系”。

| 原点选项 | 行为 |
| --- | --- |
| 保留源原点 | 保持转换后的源原点 |
| 包围盒中心 | 将所选几何的包围盒中心作为局部原点 |
| 包围盒底面中心 | 将所选几何的包围盒底面中心作为局部原点 |

初始 X/Y/Z 表示局部原点在所选父坐标系中的位置。姿态采用 **ZYX 欧拉角**，旋转矩阵为 `Rz(Rz) × Ry(Ry) × Rx(Rx)`。预览以工件局部系观察，右侧数值位姿用于提交到主场景；旋转、平移和缩放相机不会修改模型坐标或位姿。

父系可选择世界、机器人基座及当前可用的静态命名坐标系。首期不支持绑定动态工具坐标系 `t_0`。工件导入和定位不会下发机器人运动命令。

### 2.3 CAD 离散与预览观察

| 质量 | 线性偏差 | 角度偏差 |
| --- | --- | --- |
| 快速 | 0.5 mm | 30° |
| 标准（默认） | 0.1 mm | 15° |
| 精细 | 0.02 mm | 10° |

精细档通常增加三角面数量、加载时间和显存需求。更改质量后须点击“加载预览”重新读取并离散，旧候选不能提交。参数已接入实现，是否满足客户精度和性能要求仍须由真实样本验证。

预览窗口中，左键拖动旋转，鼠标中键或 Shift+左键拖动平移，滚轮缩放。可使用等轴测、前、后、左、右、上、下视角及“适应窗口”。实体、线框、实体带边线、双面观察、包围盒和统一预览颜色用于核对模型。预览的观察及颜色选项不会自动代替导入后实例的显示属性；导入后可在工件属性区设置。

### 2.4 来源快照与诊断

加载成功的候选保留源文件和必要依赖的快照。预览后若检测到主文件的时间或大小变化、文件被移走，提交前会要求选择导入已读取版本或重新加载。不要把该提示理解为已自动载入磁盘上的新内容。

加载器检查有限坐标、索引、有效表面、退化面、节点变换及容量等。少量退化面可能被跳过并记录警告。封闭性、非流形和自交当前标为“未检查”；显示成功不能作为可加工或可碰撞计算的结论。源文件只读，程序不以导入为由改写源模型。

## 3. 场景操作

在对象列表或主视口中选择工件，修改右侧属性后点击“应用属性 / 位姿”。列表中的显示复选框可直接切换对应实例的显隐。“定位选中”和“适应全部”只调整观察相机。

- 名称自动避免与现有实例重名；实例 ID 与资产 ID 不依赖显示名称。
- “锁定位姿和删除”阻止修改位姿、父系及删除；仍允许显示控制和重命名。需要移动或删除时先解除锁定。
- 可设置实体/线框/实体带边线、不透明度、统一颜色及局部坐标轴。
- 更换父系时，默认勾选“更换父系时保持世界位置”，系统换算相对位姿。取消该选项后使用新父系解释输入位姿。
- 父系失效时，工件保留最后已知的世界位置，改为世界绑定并给出警告。
- 切换 OpenGL/VTK 后端保留工件业务状态；各后端按当前状态准备各自渲染资源。

“撤销”和“重做”覆盖工件增加、属性/位姿修改、显隐和删除等内容变更，最多保留 **20 步撤销历史**。选择和相机观察不会形成内容编辑步骤。在工件面板及其子控件内可使用平台对应的撤销/重做快捷键。

## 4. 保存和恢复

点击“保存…”写入 `.r3wp` 工件场景包。包中包含去重后的工件资产、规范化几何、源文件及必要依赖快照、归一化参数、实例属性与位姿、父系引用和机器人场景上下文，因此恢复不依赖原模型仍在原路径。当前写入包版本为 v3，兼容读取 v1/v2。v3 把源快照、组件选择和网格缓存分开校验；缓存结构、缓存哈希或适配器版本失效而源快照完好时，从内存源重新生成，沿用已确认的归一化矩阵与离散参数。源或整包完整性失败时拒绝打开，保留现有场景；仅有缓存的旧资产会明确提示其恢复能力有限。STEP 外链与 OBJ 上级目录/绝对材质引用作为引用元数据保留，不会向包外解压文件。

保存采用临时数据与原子提交；写入失败时不会用半成品覆盖已有有效包。打开时先读取、校验校验和、结构及容量，再准备渲染资源，成功后才替换当前工件集合。损坏、不受支持或超限的包不会替换当前工件。

打开包前若有未保存编辑，会提示保存、放弃或取消；关闭主窗口时也会保护未保存编辑。保存按钮上的星号表示当前工件内容尚未保存。选择和相机观察不单独使场景变为未保存。

若包中的机器人型号或基座位置与当前场景不同，恢复时可选择“保持保存的世界位置”或“绑定当前父坐标系”，也可取消。打开工件包不会替换机器人配置或关节状态。该包只恢复本功能的工件状态，不是整个机器人工程文件；撤销历史和相机观察位置不作为工件包内容恢复。

## 5. 当前保护上限与故障处理

以下为实现中的保护上限，**不等同于已承诺达到这些上限时仍满足交互性能**。真实客户模型的性能指标待基准测试后冻结。

| 资源 | 当前保护上限 |
| --- | --- |
| 单个主文件 | 512 MiB |
| 资产源文件与依赖快照总量 | 1 GiB |
| 单个资产 | 500 万三角面、1500 万顶点 |
| 当前工件集合 | 50 个实例 |
| 当前资产与撤销保留资产估算 | 1.5 GiB |
| 工件场景包 | 1.5 GiB，读取另有分配预算检查 |

超限时建议在源 CAD/网格工具中简化、拆分、降低离散质量后重试。导入较多不同资产后，撤销历史仍可能保留已删除资产；保存并重新打开场景可释放这部分历史。

| 提示或现象 | 处理方式 |
| --- | --- |
| 单位未知，不能导入 | 主动选择源单位，再核对实际尺寸 |
| PLY 只有顶点，没有有效面 | 使用点云查看器，或提供有面拓扑的工件 PLY |
| 路径、依赖、解析或几何检查失败 | 查看诊断，修复路径/源文件或重新导出，重新加载 |
| 读取到企业透明加密密文头 | 由企业管理员按策略配置运行程序的读取权限；不要复制改后缀规避保护 |
| 资源或容量不足 | 降低质量、拆分模型、释放历史，检查可用内存/显存及保存盘空间 |
| CAD 功能未启用或 DLL 缺失 | 使用已验证的 OCCT 配置构建并部署对应运行依赖，核对能力说明 |
| 包损坏或版本不支持 | 保留现有场景，使用有效备份或对应版本程序 |

取消在文件读回调、阶段边界、几何提取循环及 OCCT 进度钩子处检查。Assimp 3.2 C API 的内部纯 CPU 解析不能强制中断；取消后界面废弃该会话，后台解析完成后的结果也不会提交。大文件、网络读取及最坏取消时延仍需专项实测，尚未验收有界时延。当前串行隔离 Assimp 全局错误状态及 OCCT 参数，避免并发会话串扰。

| 路线 | 入口及证据 | 当前说明 |

### 7.1 性能样本与边界

当前合成 PLY 基准分别为 40 面/120 顶点、150000 面/450000 顶点。每样本 1 次首次加载、5 次独立解析计时、50 次重新解析→规范化→添加→删除；10 ms 采样内存。每轮新建导入上下文，不使用应用几何解析缓存；不驱逐 OS 文件缓存，因此不是磁盘冷启动测量，不报告 P95 或 GPU FPS。

| 样本 | CPU 全流程中位数 / 最大值（5 次） | 生命周期采样私有内存峰值 |
| --- | --- | --- |
| 40 面 PLY | 2.82 / 3.79 ms | 28.2 MiB |
| 150000 面 PLY | 644.77 / 721.60 ms | 442.7 MiB |

全流程包含读取/解析、规范化、服务添加/删除，不含 GPU 上传与交互帧率。中等样本清空撤销历史后的私有内存变化约 -0.56 MiB；这是单次本机测量，不表示所有文件均无泄漏。GPU 界面生命周期 50 轮中，OpenGL/VTK 私有内存增长约 5.16/5.86 MiB，均低于本轮 100 MiB 保护检查。

CPU 完整记录在 `build/vscode-qt5.9.9-msvc2015_64-vtk/Release/workpiece-benchmark-validation/cpu-benchmark.json`。基准工具目标为 `robot3d_workpiece_benchmark`，支持无参数生成样本，或 `<modelpath> <out.json> [--unit-to-mm N]`。未知单位的基准样本显式按 mm 测试，不改变界面必须确认单位的规则。

### 7.2 仍需正式验收的项目

真实客户复杂曲面、开放/裁剪 IGES、不支持实体、跨软件 CAD 导出差异，仍需按需求矩阵补齐样本；当前少量标准体不能代替完整协议兼容性或工程精度验收。每类 3 个不同结构样本、每样本 5 次的全格式性能矩阵、标准场景 FPS/显存、网络中断与大文件最坏取消时延，尚未冻结并完成验收。

企业透明加密的生产白名单/目录策略和新机器部署仍需现场验证。源码通过白名单 Python 写入，保持原 BOM/行尾及加密；`build/` 下测试模型、自包含场景包、截图和便携验证资源为受控测试明文副本，需按企业策略存放。应用不更改加密策略，读取密文时明确拒绝。

应用“组件与许可…”可查看 OCCT LGPL 2.1、附加例外与部署说明，`licenses/occt-dependencies/` 包含实际第三方许可和来源校验记录。Debug CRT 只用于开发测试，不进入 Release 验证包。正式发布仍须按实际交付形式审查全部依赖材料和相关义务，本文不代表发布许可审批。

### 7.3 最终便携验证与交付入口
